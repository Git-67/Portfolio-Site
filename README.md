# Jing Heng – Personal Portfolio

My personal portfolio website, built from scratch with plain HTML, CSS, and JavaScript. No frameworks.

## Live Site

> Open `index.html` directly in a browser, or serve with any static file server.

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Inter + Space Grotesk)
- No external JS libraries or frameworks

## Sections

| Section | Description |
|---|---|
| Hero | Intro with typewriter effect |
| About | Background and summary |
| Skills | 4 categories with horizontally scrollable cards |
| Experience | Sentinel Programme, NYP Cloud & SIT clubs |
| Projects | Horrible-Alexa, Fishing-Site |
| Hackathons | Competitions attended and upcoming |
| Education | NYP + Mayflower Secondary School timeline |
| Certificates | Google Drive link to certificate folder |
| Contact | Email, GitHub, LinkedIn |

## Project Structure

```
myPortfolio/
├── index.html          # Main portfolio page
├── privacy.html        # Privacy policy
├── terms.html          # Terms of use
├── styles.css          # All styles
├── script.js           # All interactivity
├── server.js           # (Optional) Twilio SMS backend
├── package.json
├── .env.example        # Backend environment variables template
└── images/             # Logos and skill icons
```

## Features

- Responsive layout for mobile and desktop
- Dark theme with purple/blue accent
- Scroll reveal animations
- Typewriter hero effect
- Dynamic study year (auto-updates Year 1 → 2 → 3 → Graduate)
- Back to top button
- Horizontally scrollable skill cards with "Soon" badges
