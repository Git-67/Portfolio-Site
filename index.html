04 - Projects

Things I've built

AI / Voice Assistant

Horrible-Alexa

This is a homemade AI voice assistant that controls screen brightness and device volume, plays and queues music via YouTube Music, holds conversations, checks the time, sets alarms, and even drafts essays. It runs locally using Ollama (qwen3.5:9b), Whisper STT, and a Supertonic TTS engine with CUDA GPU acceleration.
